# bookmark-manager
chrome浏览器书签管理插件，使用腾讯云对象存储COS 云同步。
## 主要功能
- COS 云同步：上传/下载书签、自动定时同步、设置页面配置
- 书签树管理：多级目录折叠展开、可视化浏览
- 全局搜索：模糊匹配标题和 URL，快速定位
- 智能排序：按使用频率、最近添加、字母顺序排序
- 重复检测：URL 精确匹配 / 标题模糊匹配，批量删除
- 失效检测：并发 HTTP 检测，批量删除失效链接

## 安装使用说明
- 打开 Chrome，访问 chrome://extensions/
- 开启右上角「开发者模式」
- 点击「加载已解压的扩展程序」，选择 bookmark-manager 文件夹
- 安装后点击工具栏插件图标，进入 popup
- 点击「打开完整管理器」使用全部功能
- 右键插件图标 →「选项」进入 COS 设置页，配置腾讯云存储桶参数

## 配置腾讯云对象存储

### 创建COS访问的用户
- 这里不建议使用全局的主账户访问，因为权限太大，不安全，建议使用子账户访问，具体操作参见如下步骤。
- 打开腾讯云 COS 控制台，右上角头像 →「访问管理」 →「用户列表」 →「新建用户」 →「自定义创建」 →「可访问资源并接受消息」 →「编程访问」 → 一直点击下一步，直至完成 → 复制保存 - 密钥 ID 和 Key。

### 为子账户添加存储桶的权限
- 找到你的存储桶
- 在左侧菜单找到 「权限管理」→「存储桶访问权限」
- 点击「添加用户」 →「子账号」 →「选中刚创建的子账户」 → 勾选「数据读取-数据写入-权限读取」 → 保存。

### 设置跨域 COS 存储桶的 CORS 规则
- 找到你的存储桶
- 在左侧菜单找到 「安全管理」→「跨域访问 CORS 设置」
- 点击 「添加规则」
- 填写以下配置：
  
| 配置项             | 值                                                           |
| :----------------- | :----------------------------------------------------------- |
| **来源 Origin**    | `*`                                                          |
| **操作 Methods**   | `GET, PUT, DELETE, HEAD`                                     |
| **Allow-Headers**  | `*`                                                          |
| **Expose-Headers** | `ETag, Content-Length, Content-Type, x-cos-request-id`       |
| **超时 Max-Age**   | `3600`                                                       |


- 点击 **「保存」**
